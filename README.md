## About Me

I'm a **Full Stack Developer** and **B.Tech IT student** based in **Ahmedabad, India**. I design and build end-to-end web applications — from clean, responsive user interfaces to secure RESTful backends backed by MongoDB.

I care about writing maintainable code, shipping products that people actually use, and bringing a designer's eye (from my background in video and photo editing) to every interface I build.

- **Currently focused on:** Advanced JavaScript, React, and UI/UX design
